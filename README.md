# Фильтр Дам – сайт на согласование

Собранная версия сайта компании «Фильтр Дам»: подбор, монтаж и обслуживание
систем очистки воды для загородных домов в Москве и области.

Репозиторий содержит **готовый сайт**, а не исходники: 67 статических страниц,
один файл стилей, один скрипт, локальные шрифты. Ни сборщиков, ни зависимостей –
страницы открываются как есть.

## Смотреть

**https://savamurk.github.io/water-clear/**

Публикуется через GitHub Pages из ветки `main`, папка `/`.

## Как обновить

Сайт собирается генератором в отдельном проекте (`build.ps1`), сюда попадает
только результат. Порядок такой:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1   # собрать страницы
powershell -NoProfile -ExecutionPolicy Bypass -File .\dist.ps1    # отобрать то, что уезжает
```

Затем скопировать содержимое `dist` в папку этого репозитория и отправить:

```powershell
git add -A
git commit -m "Что изменилось"
git push
```

Публикация обновляется сама через минуту-две. Если браузер показывает старую
версию – это кэш, откройте адрес с любым параметром, например `?v=2`.

## Что важно знать при просмотре

**Сайт закрыт от поисковиков.** Все страницы помечены `noindex`, в `robots.txt`
стоит запрет обхода – это черновик на согласование, в выдачу он попасть
не должен.

**Форма заявки ничего не отправляет.** Приём заявок не подключён: форма
проверяет заполнение и честно сообщает, что данные никуда не ушли.
Номер телефона в шапке пока тоже условный.

**Часть данных вымышлена.** Цены, характеристики комплекта, кейс и отзыв –
черновые, они заменяются на реальные перед запуском.

**Тринадцать страниц без фотографий.** Девять услуг и четыре страницы анализа
воды ждут своих кадров и пока выглядят суше остальных.

## Служебные файлы

| Файл | Зачем |
|---|---|
| `.htaccess` | заголовки безопасности и кэширования для Apache |
| `security-headers.nginx.conf` | то же самое для nginx |
| `.nojekyll` | отключает обработку страниц движком Jekyll на GitHub Pages |

На GitHub Pages первые два не работают – они нужны при переносе на обычный
хостинг.
